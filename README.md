## 🔬 Project Spotlight

> The one I'd open if you asked *"what's the most interesting thing you've built?"*

```
┌─────────────────────────────────────────────┐
│  SMART-PROCURE                               │
│                                              │
│  AI-powered procurement platform for SMEs    │
│                                              │
│  Next.js → NestJS → PostgreSQL/Prisma → AI   │
│                                              │
│  [ Repository ]                              │
└─────────────────────────────────────────────┘
```

- **What it does** — turns scattered vendor talks, quote spreadsheets and approval threads into one automated procurement system with AI price analysis and anomaly detection.
- **The interesting bit** — the AI runs fully local via Ollama/LLaMA by default with a Gemini cloud fallback, so "enterprise Intelligence" costs zero vendor fees.
- **Why I built it** — small businesses still run core workflows over WhatsApp chats and Excel files; I wanted to prove that local, cheap AI could quietly fix that.
