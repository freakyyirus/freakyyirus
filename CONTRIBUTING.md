# Contribution Guidelines

Thanks for your interest in contributing! Small repositories benefit greatly from clear, simple contribution steps.

How to contribute
- Open an issue describing the bug, feature, or improvement.
- Fork the repo and create a topic branch for your change.
- Write clear commit messages and include tests or examples when applicable.
- Submit a pull request describing your changes and linking any related issues.

Code style
- Keep code and scripts simple and well-documented.
- Prefer small, focused pull requests.

Other notes
- Use GitHub Issues for discussions.
- For major changes, open an issue first so maintainers can provide guidance.

Thank you — contributions are welcome!
